# VimVader 👾

Vimのキーバインドで操作するターミナルインベーダーゲーム。

## 起動

```bash
node vimvader.js
```

Node.js のみ必要（外部ライブラリ不要）。

## 操作

### Normal モード（デフォルト）

| キー | 動作 |
|------|------|
| `h`  | 左移動 |
| `l`  | 右移動 |
| `k`  | 上移動 |
| `j`  | 下移動 |
| `i`  | Insert モードへ |
| `q`  | ゲーム終了 |

### Insert モード

| キー | 動作 |
|------|------|
| 任意の文字 | その文字を弾として発射 |
| `ESC` | Normal モードに戻る |

## ゲームルール

- 敵（👾）が画面上部から降りてくる
- 自機（▲）を動かして弾を当てて撃破
- 敵が画面下部に到達するとゲームオーバー
- 全敵撃破で次のウェーブへ（ボーナス +100点）
- 敵1体撃破 = +10点
